
# HOW TO INSTALL AND WIRE AN INDUCTIVE PROXIMITY SENSOR ON A CONVEYOR LINE 

## CAUTION AND PERSONAL SAFETY 

1.High voltage hazard!,you are to handle 120V ac power supply  
2.First DE-Energize and lockout tag-out before opening the control
panel  
3.Must wear insulated shoes and gloves while working with the power
supply.

##  EQUIPMENT AND TOOL

1.An proximity sensor \[3-wire dc\] provided with kit  
2.Mounting Bracket  
3.M12 locking nut

### TOOLS

1.A flathead precision screwdriver  
2.Wire Stripper  
3.Electrical Insulated Tape

## INSTALLATION PROCEDURE

1.  Verify the power supply is disconnected and conveyor is stopped
    operating.

2.  Position the sensor onto the mounting bracket.

3.  Install the sensor at 15mm distance from conveyor belt.

4.  Wire the sensor as shown in the diagram.

5.  Torque the mounting nut to 5NM.

6.  observe the led indicator for red light for a successful
    installation.

## VERIFICATION

1.  Verify the connection and reconnect the power supply

2.  An green light indicates proper function, otherwise, the operation
    is faulty.

## TROUBLE SHOOTING 

1.  follow only when faulty operation.

2.  verify the wiring connection in the control box

3.  Ensure stable power supply.

4.  check the plc module for fault
